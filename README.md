# MAM ✨
Un chat sencillo en español con un pequeño modelo de inteligencia artificial ejecutado en el navegador mediante Transformers.js y Qwen2.5-0.5B-Instruct.

## Uso
Abre `index.html` mediante un servidor web o en una publicación estática. La primera respuesta descarga el modelo de Hugging Face y puede tardar y requerir memoria y datos. Una vez cargado, el modelo genera las respuestas en el dispositivo; el navegador también descarga la biblioteca desde jsDelivr. La calidad es limitada y puede cometer errores. Evita introducir información privada.

No se necesita clave de API. No incluyas contraseñas ni claves en el código. GitHub Pages gratuito puede requerir que el repositorio sea público; revisa su visibilidad antes de publicarlo.
